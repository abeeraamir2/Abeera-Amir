# 📚 Class-Based Tasks

This folder is dedicated to coursework, classroom exercises, and practical assignments.

---

## 📂 Structure

Organize your class tasks here by topic, date, or assignment number:

```
Class-Tasks/
├── README.md               # Class tasks overview & index
├── Lab-Exercises/          # In-class coding exercises
└── Assignments/            # Graded assignments and projects
```

---

## 📌 Usage
- Place your `.py` scripts, Jupyter notebooks (`.ipynb`), or datasets directly in this directory or in relevant subfolders.
- Commit your updates using GitHub Desktop to keep your repository organized.
